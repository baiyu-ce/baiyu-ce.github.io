# Visual assets

`assets/ocean-depth-v2.png` is an original AI-generated conceptual ocean image created with the built-in image generation tool for this project on 4 October 2026. It illustrates the metaphor of tracing evidence below a visible failure. It is not a photograph from the referenced Douyin video and is not research evidence.

The visual direction was inspired by the user's description of scrolling into the ocean. The linked reference video could not be accessed in the authoring environment, so no claim of a frame-by-frame reproduction is made.

All website typography, diagrams, interactions, and educational traces are implemented in the site's own HTML, CSS and JavaScript. Educational traces are fictional, prewritten examples; they are not model-generated experiment outputs.
