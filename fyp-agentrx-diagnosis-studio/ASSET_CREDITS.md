# Visual assets

`assets/surface-v3.png` and `assets/underwater-v3.png` are original AI-generated conceptual ocean images created with the built-in image generation tool for this project on 4 October 2026. They illustrate the metaphor of tracing evidence below a visible failure. Neither image is a frame from the reference video, and neither is research evidence. The older `assets/ocean-depth-v2.png` is retained as a previous version and is no longer loaded by the page.

The first version followed the user's written description because the shared video link was unavailable. The user then provided the video file; its surface, waterline crossing, and underwater sequence informed the current composition and transitions. Reference footage and extracted frames are not distributed in this website. Water motion and refraction are independently implemented as decorative WebGL effects, with static CSS fallbacks; this is an interpretation, not an exact reproduction or a physical ocean simulation.

All website typography, diagrams, interactions, and educational traces are implemented in the site's own HTML, CSS and JavaScript. Educational traces are fictional, prewritten examples; they are not model-generated experiment outputs.
