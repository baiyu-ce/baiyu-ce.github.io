# Campus photography attribution

The homepage carousel uses nine locally optimized copies of photographs supplied by the site owner. The photographs correspond to the campus tour images presented on the University of Hong Kong Development & Alumni Affairs Office's Class Reunion page.

## Current homepage carousel

The carousel contains:

- `hku-centennial-wall.webp` — Centennial Wall
- `hku-hung-hing-ying-building.webp` — Hung Hing Ying Building
- `hku-main-building-arch.webp` — Main Building
- `hku-run-run-shaw-heritage-house.webp` — Run Run Shaw Heritage House
- `hku-fung-ping-shan-building.webp` — Fung Ping Shan Building
- `hku-main-library.webp` — Main Library
- `hku-knowles-building.webp` — Knowles Building
- `hku-university-street-gallery.webp` — University Street
- `hku-centennial-campus.webp` — Centennial Campus

- Source page: https://alumnigiving.hku.hk/hku-class-reunion/
- Processing: orientation normalized, resized to fit within 1920 × 1280 pixels without enlargement, and converted to WebP for web delivery.
- Copyright: remains with The University of Hong Kong and the photographers or other rights holders.
- Licence status: these photographs are not claimed to be open-licensed by this portfolio.

The source page states © The University of Hong Kong. All rights reserved. The source link and rights notice are displayed in the website footer. Permission should be obtained from the rights holder for republication beyond the original source context.
